# AngelBounty

Production-safe Paper plugin scaffold for Minecraft 1.21.11.

Package:
- `me.angelique.angelBounty`

Main class:
- `me.angelique.angelBounty.AngelBounty`

Features:
- 1 to 6 wanted stars by player kills
- TAB prefix
- Nametag prefix above player head using scoreboard teams
- Sidebar wanted board
- `/wanted top`
- Persistent YAML storage in `plugins/AngelBounty/wanted-data.yml`
- Optional Vault economy support
